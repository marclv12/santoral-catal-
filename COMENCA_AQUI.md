# Comença aquí

Per posar en marxa **Bon Dia Catalunya** sense Visual Studio:

1. Obre **[GUIA_CONFIGURACIO.md](GUIA_CONFIGURACIO.md)** i segueix-la des del principi.
2. Utilitza **[CHECKLIST_POSADA_EN_MARXA.md](CHECKLIST_POSADA_EN_MARXA.md)** mentre avances.
3. No publiquis mai el token del bot: desa’l únicament com a secret de GitHub.

Ordre de les quatre proves finals a la pestanya **Actions**:

1. `Comprova el projecte`
2. `Comprova la connexió amb Telegram`
3. `Actualitza la fitxa diària`
4. `Envia el bon dia a Telegram`

Quan les quatre acabin en verd, el sistema queda automatitzat:

- web actualitzat a les 06.40 h;
- missatge enviat a les 07.00 h;
- hora de Madrid, amb canvi d’horari automàtic.
